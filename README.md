Gummble is an organized library of 300,000+ real UI screenshots from shipped iOS, Android, and web apps. It provides designers with a curated collection of UI design inspiration, showcasing real app screens, flows, and patterns to help accelerate product design and improve user experience. The platform aims to make UI design inspiration accessible to every designer, offering searchable categories, tags, and high‑quality visuals.

Founded to bridge the gap between design theory and real‑world implementations, Gummble continuously updates its library with fresh releases, ensuring designers have up‑to‑date references for modern app design trends.

**Areas:** Company · UI · Design · Inspiration · Screenshots

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Gummble: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
